HVAC Territory Discovery v0.11.12 — Validation Notes
====================================================

Scope
-----
This release is a Newport News data adapter and a deployment-routing change. It does not retrain the
detector or change primary inference thresholds. Chesapeake remains covered by regression tests but
is removed from the selectable UI until a better imagery source is available.

Acquisition controls
--------------------
- Newport News address matching uses normalized FULLADDR records, not loose metadata matching.
- Parcel discovery retains PARCELID, SITEADDRESS, ASMT_LANDUSE, USEDSCRP, CLASSDSCRP, zoning,
  ownership, and raw use/class codes for audit.
- Current official PLACENAME address records join to parcels by PARCELID as facility hints.
- Building FEATURECODE values map to residential, commercial, public, or miscellaneous context;
  BLDGHEIGHT is retained when available.
- Missing required Newport News footprints stops discovery before prescreening.
- VGIN image requests preserve the existing Web Mercator frame, physical side length, and 1800-pixel
  detector input. JSON errors, blank exports, unreadable data, and wrong dimensions remain fatal.

Detector controls
-----------------
- Detector baseline remains v0.11.7 with v0.0.12 model assets.
- Primary operating points remain 0.07 / 0.35 / 0.45.
- The only bounded territory-rule extension is that the existing context-only manual review for a
  medical campus with a >=100,000-ft2 building now recognizes Newport News.
- Prior Norfolk, Virginia Beach, and Chesapeake adapter regressions remain in the suite.

Recommended validation
----------------------
Run a fresh Newport News area at 0.5 mile / 10,000 ft2. Review every STRONG and REVIEW result and a
sample of QUIET results. Send the annotated CSV first, followed only by individual property folders
for definite misses, confusing false positives, or especially useful controls.

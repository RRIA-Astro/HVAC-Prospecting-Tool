HVAC Deep Vision v0.6.1 — Windows EXE Builder

WHY THIS PACKAGE EXISTS
Your Windows PC does not currently expose Python through either the `py` or `python` command.
Rather than requiring a local Python setup, this project uses a GitHub-hosted Windows runner to
build a standalone EXE. PyInstaller must build a Windows executable on Windows.

WHAT THE BUILD PRODUCES
HVAC_Deep_Vision_v061.exe

The resulting EXE includes Python and the required Python dependencies. The target PC does not
need Python installed.

BUILD STEPS
1. Create a new GitHub repository (private is fine).
2. Upload ALL contents of this folder, including the hidden .github folder.
3. Commit/push them to the repository's main branch.
4. Open the repository's Actions tab.
5. Open the workflow named "Build Windows EXE".
6. Run it manually if it did not start automatically.
7. When the workflow finishes, open the completed run.
8. Download the artifact named "HVAC-Deep-Vision-Windows".
9. Extract the downloaded ZIP.
10. Double-click HVAC_Deep_Vision_v061.exe.

The API key is NOT included in the repository or EXE. Enter it only after the app is running.
Do not commit your API key to GitHub.

If Windows SmartScreen warns about the EXE, that can happen because this prototype is unsigned.
Only run an executable that you built from your own repository/workflow.

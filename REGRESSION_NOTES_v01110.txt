At 124 W Freemason, grouped rooftop equipment remains a plausible REVIEW from the detector's view;

Release logic
-------------
- Norfolk 1800-pixel rescue views now use sixteen overlapping 512-pixel crops with no uncovered
  source-image bands. Virginia Beach and unscoped tests retain the exact nine-crop baseline.
- Norfolk school/government/industrial/institutional priority sites and qualifying urban hotels use
  a 50,000-ft2 focus floor. Other Norfolk sites and all Virginia Beach sites stay at 75,000 ft2.
- HOTEL/MOTEL wording alone is insufficient. The urban-hotel path requires size plus density (or
  explicit convention identity), and only enables imagery/rescue; it cannot manufacture evidence.
- On a <=100,000-ft2, single-building Norfolk site, retained rescue evidence must be within 10 ft
  of the parcel or within 5 ft of the joined target footprint. Normal detections are unchanged.
- Model files, normal inference, all verifier thresholds, and triage thresholds are unchanged.

Regression coverage
-------------------
The 78-test offline suite covers grid geometry, hotel qualification, focus-floor routing, small-site
attribution, the acceptable Freemason REVIEW, prior field controls, Virginia Beach preservation,
source routing, imagery validation, build naming, checkpoint integrity, and bundle checks.

The local scratch runtime does not include torch/torchvision/ultralytics, so full model loading and
PyInstaller assembly remain GitHub Actions checks. The workflow validates checkpoint archives, loads
the actual source models, verifies bundled SHA256 equality, and loads the bundled models before it
publishes the Windows artifact.
